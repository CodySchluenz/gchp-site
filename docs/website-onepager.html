The Website: Domain & Cloudflare

Who runs what, what it costs, and who to call — updated July 2026.

Website address
grantcountyholidayproject.org — this is the "domain name," the address families type to find us. It is registered with Cloudflare and renews every July ($8.95 a year, charged to the billing information saved on the Cloudflare account — the coordinator's, as of July 2026). The old .com address is retired.
Cloudflare
Cloudflare is the company whose computers run our website. It serves every page, keeps the applications database (every family's application, your notes, the history), stores the blank paper-application PDFs, and protects the admin sign-in. We use their free plan: $0 per month. The account belongs to Cody Schluenz (codydps@gmail.com).
Email
The emails the website sends — application confirmations, approval letters, your sign-in link — go out through a service called Resend (also free), from no-reply@grantcountyholidayproject.org.
The recipe
The website's code — its complete recipe — is kept safe at github.com/CodySchluenz/gchp-site. With it, any web developer could rebuild the whole site.
Upkeep
Nothing needs monthly attention. The site runs itself; the only yearly item is the domain renewal each July. Applications are kept season by season for the county audit — nothing is ever purged automatically.

If the website is ever down, or help is needed

Contact Cody Schluenz — codydps@gmail.com.

If Cody is unavailable, any web developer can take over: everything technical is written down, step by step, in the Website Operations Manual (a copy belongs in this guidebook, and one lives with the code itself).
